# Como publicar no GitHub Pages

## Novo repositório
1. Acesse github.com → "New repository"
2. Nome: `mgcoach-organizer` (ou outro de sua escolha)
3. Marque **Public**
4. Clique em "Create repository"
5. Vá em "Add file" → "Upload files"
6. Suba: `index.html`, `sw.js`, `manifest.json`
7. Commit → aguarde ~3 min → acesse `seu-usuario.github.io/mgcoach-organizer/`

## Atualizar versão existente
1. Abra o repositório no GitHub
2. Clique no arquivo → ✏️ editar (ou "Add file" → substituir)
3. Commit → aguarde ~2 min
4. No celular: Configurações do app → "Atualizar" ou abra em aba anônima

## IMPORTANTE
- Dados ficam no IndexedDB do dispositivo (sem nuvem)
- Use o botão de exportar/importar para backup manual
- Não limpe os dados do navegador sem fazer backup
